# Nexrive Web

Sitio corporativo de Nexrive: https://nexrive.github.io

Sitio estático en español (`/`) e inglés (`/en/`). Los textos están en `locales/`, la estructura en `src/` y las páginas se generan con `npm run build`. Requiere Node 20 o superior y no tiene dependencias.

```bash
npm run check
```

```bash
npm run serve
```

Documentación en `docs/`; empezar por `docs/PROJECT_MAP.md`.
